# F1 Landing Page

Landing page inspirada no universo da Fórmula 1, desenvolvida como um projeto acadêmico e também como oportunidade para aprimorar habilidades em desenvolvimento web front-end.

O projeto simula um portal de notícias relacionado à Fórmula 1, com foco na apresentação de conteúdos de forma visual, responsiva e organizada.

# Tecnologias utilizadas
HTML5 — estruturação semântica das páginas.
CSS3 — estilização e personalização da interface.
Bootstrap — desenvolvimento do layout responsivo e utilização de componentes pré-estilizados.
JavaScript (ES6+) — implementação de comportamentos e interações dinâmicas.

# Objetivos

O principal objetivo do projeto foi colocar em prática conhecimentos previamente adquiridos em HTML, CSS e JavaScript, ao mesmo tempo em que explorei o Bootstrap e seus recursos para desenvolvimento de interfaces responsivas.

Além do aspecto acadêmico, o projeto foi desenvolvido com a intenção de simular a construção de uma aplicação web real, considerando aspectos como:

organização e estruturação do código;
responsividade para diferentes dispositivos;
criação de uma interface visualmente consistente;
utilização de componentes do Bootstrap;
implementação de interações com JavaScript.

# Sobre o projeto

A escolha da Fórmula 1 como tema surgiu tanto pelo interesse pessoal na categoria quanto pela possibilidade de explorar uma identidade visual marcante e um contexto semelhante ao de um portal de notícias.

A proposta foi criar uma experiência que combinasse informação, identidade visual e usabilidade, utilizando a Fórmula 1 como inspiração para a construção da interface.

# Aprendizados

Durante o desenvolvimento, pude aprofundar meus conhecimentos em HTML, CSS e JavaScript e, principalmente, compreender melhor como o Bootstrap pode ser utilizado na construção de layouts responsivos.

O projeto também serviu como exercício para aplicar conceitos de desenvolvimento front-end em uma aplicação com uma proposta mais próxima de um produto real.
